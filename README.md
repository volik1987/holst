# Холст

Редактор интерфейсов в браузере — свой аналог Figma на чистом JavaScript, без сборки и без сервера.

**Открыть:** https://volik1987.github.io/holst/

## Что умеет

- Бесконечный холст на Canvas2D: масштаб, сдвиг, пиксельная сетка, страницы.
- Фреймы, прямоугольники, эллипсы, линии, текст, перо (кривые Безье) и правка точек контура.
- Выделение, рамка, ручки размера и поворота, умные направляющие, расстояния по Alt.
- Группы, вложенные фреймы с обрезкой, ограничения (constraints).
- Авто-раскладка (ряд/колонка, отступы, промежутки, «по содержимому» / «заполнить»).
- Компоненты и экземпляры с переопределениями, замена компонента, отсоединение.
- Цветовые переменные со светлым и тёмным режимом, режим на фрейм.
- Заливки: цвет, линейный и радиальный градиент, картинка. Обводки, тени, размытие, режимы наложения.
- Булевы операции: объединение, вычитание, пересечение, исключение.
- Прототип: переходы по щелчку с анимацией, режим показа.
- Экспорт PNG/JPG/SVG, HTML+CSS, панель «Код» с CSS. Импорт SVG и картинок.
- Автосохранение в браузере (IndexedDB), файлы `.holst`, работа офлайн (PWA).
- Совместная работа в реальном времени через WebRTC (PeerJS), без своего сервера.

## Устройство

| Файл | Что внутри |
|---|---|
| `js/model.js` | документ (плоская карта узлов), история, авто-раскладка, экземпляры, разница для сети |
| `js/render.js` | отрисовка узлов, булевы операции, попадание курсора |
| `js/canvas.js` | холст: мышь, инструменты, направляющие, оверлеи |
| `js/ui.js` | панели: слои, ресурсы, инспектор, прототип, код |
| `js/io.js` | файлы, импорт SVG, экспорт PNG/SVG/HTML, CSS |
| `js/proto.js` | показ прототипа |
| `js/collab.js` | совместная работа |

## Тесты

```bash
node --test tests/                                   # модель
node tests/collab-e2e.mjs http://localhost:8812      # два браузера по WebRTC
```

В открытой странице: `(await import('/tests/ui-e2e.js?' + Date.now())).run()` — сквозной тест интерфейса.
